💡 The 60-Second Layman Summary

The Old Way (Cloud CDP / Adobe Alloy): Every click, scroll, and search query is shipped across the internet to corporate servers. Servers compute intent and respond 400ms later. It is slow, violates privacy, and gets blocked by ad-blockers.

The GemmaEdge Way: Your device has a tiny, ultra-fast embedding model running in memory. It computes intent in under 1.5 milliseconds with 0 bytes leaving your machine. Unbreakable privacy, zero cloud hosting bills, zero lag.

The 5 Decoupled Feature Bricks

Built with zero external npm runtime dependencies. Reusable in web apps, mobile WebViews, and extensions.

Brick 1: collector-brick.js

Standard XDM-Lite client collector with an in-memory ring buffer that condenses clicks into natural trajectory narratives.

Brick 2: slm-adapter-brick.js

Pluggable SLM interface featuring Matryoshka Representation Learning (MRL 256d/128d) and runtime LoRA hot-swapping.

Brick 3: segmenter-brick.js

Local CJA intent classifier computing cosine similarity against natural-language Segment Prototypes in under 1ms.

Brick 4: mutator-brick.js

Reactive DOM experience adapter that cross-fades hero messaging, badges, and CTAs in under 15ms with zero layout shifts.

Brick 5: inspector-brick.js

Real-time diagnostic panel displaying live XDM JSON streams, vector angles, and a verified 0-byte air-gap meter.
