FrameMind Architectural & Strategic Report

FrameMind transforms raw video capture into broadcast-grade framed content entirely on-device using a quantized Small Language Model (SLM) and dynamic LoRA adapters.

1. Architectural Differentiation

Dimension Cloud Editing (OpusClip, Descript) FrameMind (On-Edge SLM)

2. Feature-Brick Composition

FrameMind is constructed from 4 decoupled feature bricks adhering to the 864zeros architectural standard:

  • AudioCollectorBrick: Ingests rolling speech tokens, acoustic dB energy levels, silence pauses, and cue tags.
  • SlmCinematographyBrick: Vectorizes conversational trajectories into 256d space and hot-swaps task LoRA adapters in <0.1ms.
  • DirectorBrick: Evaluates vector cosine similarity against cinematographic shot prototypes and outputs non-destructive Edit Decision Lists (EDL).
  • FramingMutatorBrick: Renders smooth cubic-bezier camera transitions (Pan/Tilt/Zoom) into 9:16 Short/Reel viewports while enforcing boundary safety.

Feature Bricks API & Code Contracts

All bricks are pure ES modules with zero external npm runtime dependencies.

1. AudioCollectorBrick Contract

const collector = new AudioCollectorBrick({ maxWindowSeconds: 12 });
collector.ingest({ timestampMs: Date.now(), word: 'punchline', speaker: 'host', dbLevel: -10 });
const trajectory = collector.synthesizeTrajectory();

2. SlmCinematographyBrick & LoRA Swapping

const slm = new SlmCinematographyBrick();
slm.swapLora('fitness_coach'); // Instant hot-swap in 0.047ms
const vector = slm.embed(trajectory);

3. DirectorBrick Decisioning

const director = new DirectorBrick(slm);
const decision = director.directShot(trajectory, { speaker: 'host' });
// Output: { shotKey: 'PUNCHLINE_PUSH', confidence: 0.92, cameraParams: { zoom: 1.35, panX: 0.5 } }
